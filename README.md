# Fundamentos de Desarrollo Web con HTML y CSS

## Resumen del Curso

Este curso introductorio tiene como propósito enseñar los fundamentos del desarrollo web a estudiantes de secundaria entre 12 y 17 años que no cuentan con experiencia previa en programación. A través de una metodología práctica y orientada al aprendizaje progresivo, los participantes conocerán las tecnologías básicas utilizadas para construir sitios web modernos: HTML y CSS.

Durante el desarrollo del curso, los estudiantes aprenderán a crear páginas web desde cero utilizando herramientas en línea gratuitas, evitando la necesidad de instalar software adicional. Cada lección combina conceptos teóricos con ejercicios prácticos que permiten aplicar inmediatamente los conocimientos adquiridos. Como proyecto final, se desarrollará una página web temática denominada **Space Explorer**, en la que se integrarán todos los conceptos vistos a lo largo del curso.

**Duración total:** 60 minutos (5 lecciones de aproximadamente 12 minutos cada una)

**Público objetivo:** Estudiantes de secundaria (12 a 17 años)

**Prerrequisitos:** Ninguno

**Herramientas necesarias:** Navegador web (Google Chrome, Mozilla Firefox, Microsoft Edge o Safari)

**Repositorio de código fuente:**  
https://github.com/upc-pre-202610-1asi0730-20177-cryologic/webdev-course-webgeeks

### Descripción

En esta primera lección se presentarán los conceptos fundamentales del desarrollo web, explicando qué es una página web, cómo funciona Internet y cuál es el papel de los navegadores web en la visualización de contenido. Los estudiantes conocerán las tecnologías principales utilizadas en la construcción de sitios web y comprenderán la diferencia entre HTML y CSS.

Posteriormente, se introducirá la estructura básica de un documento HTML, explicando el propósito de etiquetas esenciales como `html`, `head`, `body`, `h1`, `p` y `button`. A través de ejemplos prácticos desarrollados en un editor en línea, los participantes crearán su primera página web y observarán cómo se organiza el contenido dentro de un documento HTML.

### Objetivos de Aprendizaje

- Comprender qué es el desarrollo web.
- Identificar los componentes principales de una página web.
- Reconocer la estructura básica de un documento HTML.
- Crear una página web sencilla utilizando etiquetas fundamentales.

- Utilizar enlaces internos dentro de una página web.

### Descripción

En esta sesión se introducirá el uso de CSS Grid como una herramienta moderna para la organización de elementos visuales dentro de una página web. Los estudiantes aprenderán a distribuir imágenes en filas y columnas de manera ordenada y adaptable a distintos tamaños de pantalla.

La práctica consistirá en construir una galería espacial compuesta por imágenes relacionadas con el universo, aplicando conceptos de diseño visual y organización del contenido. Asimismo, se explicará cómo CSS Grid permite crear diseños más flexibles y profesionales en comparación con otros métodos tradicionales de posicionamiento.

### Objetivos de Aprendizaje

- Comprender el funcionamiento de CSS Grid.
- Organizar elementos visuales en una cuadrícula.
- Crear galerías de imágenes atractivas.

Los estudiantes aprenderán a diseñar tarjetas informativas que presenten información sobre astronautas históricos, utilizando propiedades CSS para controlar colores, bordes, sombras y espaciados.
